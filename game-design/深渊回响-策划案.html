1. 设计支柱 (Design Pillars)

所有玩法决策最终都要能回溯到这三条，任何与之冲突的提案一律否决。

支柱一：装备即玩法，而非装备即数值

装备的部位决定你获得什么能力，而不是只决定你的攻击力大 3%。换一把武器不是把数字从 100 变成 103，而是把「三段挥砍」换成「贯穿突刺」，整套 Build 的手感会变。

落地约束：任何一次装备掉落，必须至少改变一项行为（技能形态、触发条件、结算方式）。纯数值提升的掉落只允许出现在 T0/T1 品质。

支柱二：每一次掉落都是一次赌

掉落是纯随机的，但玩家永远有决策：要不要为了「词缀更好但部位不对」的装备放弃当前 Build，要不要花残片洗掉一条不合 Build 的词缀。

落地约束：深渊内必须有「锁定 / 洗练 / 跳过掉落」三种玩家操作，任何掉落都不能自动进背包。

支柱三：暗黑卡通 = 高对比剪影，而非血腥写实

美术走剪影 + 描边 + 高饱和点缀，不做写实脏污。装备品质靠发光边框 + 图标符号区分，不靠精细贴图。

落地约束：单件装备图标成本预算 ≤ 15 分钟，7 部位 × 6 品质 = 42 个基础图标靠换色 + 换前缀角标复用。

3. 世界观与叙事

3.1 设定

大陆历末，深渊裂开了一道口子。裂口不会喷出怪物，它回放——把死者生前的战斗一遍遍演给你看。每一场战斗都是某个人死前那一战的复刻。

「深渊回响」是冒险者对这道裂口的俗称。越往深处走，回响越清晰，到第七层你甚至能看见对手当年的走位和犹豫。

3.2 玩家身份

拾遗者：专门进入深渊、带回回响之物的赏金猎人。不问正义，只问价码。玩家的装备不是「打造」出来的，是从回响里拾回来的。

3.3 叙事载体（低成本、可扩展）

  • 章节过场：立绘 + 竖版对话框，每章 2–3 段
  • 深渊日志：进入深渊时随机抽 1–2 条前人日志（纯文本，几十条复用），提供世界感而不占产能
  • 装备图鉴：每件暗金附带一段短描述，收集即叙事

产能提示：叙事不驱动产能规划。12 章 × 3 段 = 36 段过场 + 60 条日志 + 12 件暗金描述 = 一名文案 + 一名兼职插画可覆盖。

前缀规则：

  1. 前缀由品质决定，玩家的基础词缀名永远带前缀，一眼可判品质
  2. 前缀决定该装备的词缀倾向（例：「炎魔的」必带火伤，「亡者的」必带吸血/召唤）
  3. 前缀是美术与音效的第一识别位（图标左上角角标 + 名称首字高亮）

4.3 词缀系统

通用属性池（无部位限制）：攻击力、攻击速度、暴击率、暴击伤害、生命值、护甲、闪避、移速、伤害减免、格挡率、格挡强度、生命偷取、治疗加成、冷却缩减、技能等级、资源回复。

元素属性池：火焰 / 冰霜 / 雷 / 暗影 / 物理 伤害与抗性。

状态池（异常）：燃烧 / 流血 / 中毒 / 冰冻 / 眩晕 / 沉默 / 束缚 / 减速。

关键约束（防组合爆炸）：

  • 部位不重复：同一部位不会出现两条同权重词缀（如武器不会同时给两条攻击速度）
  • 词缀可跨部位：暴击率可出现在武器/鞋/头盔，形成多来源 Build 可能性
  • 全局词缀上限：同一词缀在 7 个部位上最多出现 3 次

4.6 掉落生成算法

生成一件装备：
1. 决定品质     P(quality) = base[quality] × 幸运修正 × 深渊层数修正 × 套装标记
2. 决定部位     按怪物掉落表权重随机（精英/Boss 有部位权重偏移）
3. 决定基底     该部位该品质下的基底名池随机（如「猎颅」「裂魂」「守望」）
4. 决定前缀     从该品质前缀池随机 → 决定词缀倾向
5. 决定词缀     按部位权重池采样 N 条（互斥规则约束）→ 套用前缀倾向
6. 决定数值     每条词缀在 [min, max] 区间 roll，稀有度影响区间宽度
7. 判定传说特性  T5+ 概率触发 1 条，T6 概率触发 2 条（池按品质+部位限定）
8. 生成 Item ID  写入唯一实例 ID 与 roll 后的最终数值

掉落表归属：怪物身上挂 dropTableId → 表内定义 equipChance、qualityWeights[]、slotWeights[]、minQuality。章节越深，Boss 的 minQuality 越高。

4.7 装备评分 (Item Power)

用于 UI 快速对比与深渊难度匹配，不参与实际战斗计算。 ItemPower = 品质基线(品质) × (1 + Σ词缀权重 × 0.08) × (1 + 传说特性数 × 0.15) 品质基线：T0=1, T1=3, T2=8, T3=18, T4=35, T5=65, T6=110, T7=160

4.8 铁匠铺系统

功能 消耗 产出 说明
分解 装备 锻造石 + 部位碎片 T0/T1 全自动，T2+ 需二次确认（防误分解）
锻造 锻造石 + 图纸 指定部位 + 指定品质的新装备 品质由图纸决定，词缀随机；这是定向获取套装的路径
附魔 深渊结晶 给装备附加 1 条「特性」（非词缀） 特性永久附加，可洗
洗练 残片 重掷某一条词缀的数值区间 只能洗数值，不改词缀类型与品质
鉴定 金币 开出未鉴定装备的真实属性 鉴定费随词缀数递增；鉴定前只显示颜色
分解进阶 锻造石 + 部位碎片 把 3 件同品质同部位合成 1 件高一品质 品质上限受图纸约束
订单 — 金币 + 声望 NPC 每日订单：要某部位某品质以上 / 要某套装部件
寄售 金币 声望 把不需要的装备挂出去，等其他玩家买（可选，联网版）

未鉴定装备是铁匠铺的核心张力来源：深渊里掉下一件未鉴定的橙装，你无法判断它是否值得洗练——先花金币鉴定还是先跑路？这是免费产生「二选一决策」的低成本设计。

5. 战斗系统

5.1 视角与操作

  • 2D 等距视角（45° 斜俯视），参考《暗黑破坏神》《火炬之光》手游化形态
  • 虚拟摇杆移动 + 点击技能施放，普攻自动索敌
  • 单局怪物数量 8–25 只，全员同屏，靠位移与技能规避而非硬拼

5.2 技能系统

  • 技能栏 6 格：第 1 格固定为武器主动技，其余 5 格由其他部位竞争
  • 冷却采用充能式（充能数 = 基础充能 + 冷却缩减），避免"技能转好了却用不掉"的挫败
  • 怒气/资源条：普攻与击杀积累，消耗释放，武器主动技是主要消费口
  • 每个部位主动技有 3 个等级（来自装备技能等级词缀或铁匠铺强化），等级提升改变数值 + 解锁 1 个变体（如恐惧冲击 Lv3 变为吸附型）

5.3 敌人与战斗威胁类型

类型 行为 应对
近战冲锋 直冲玩家，接触伤害 位移 / 护盾格挡
远程弹幕 定点发射可躲避弹体 走位，不贪输出
施法者 蓄力 1.5s 后 AoE 打断（用主动技）
召唤者 持续生成小怪 优先清召唤者
护盾者 必须破盾才能伤害 集中爆发
回声者 复制玩家 3 秒前的操作 时机管理

「回声者」是本作特色敌人：它复刻玩家刚才的技能与走位，逼迫玩家改变行为而不是重复输出。设计意图是把「回响」世界观落到战斗机制上。

5.4 死亡与惩罚

  • 普通关卡：原地复活，掉落物保留
  • 深渊：死亡则本层掉落全部损失（已拾取装备保留，未拾取的留在尸体可二次拾取），损失一半深渊结晶
  • 不做体力/耐久惩罚，只做时间成本惩罚

6. 回响深渊（Roguelite 副本）

6.1 结构

  • 深渊分 若干章（Depth Cycle），每章 10 层：第 1–8 层普通节点，第 9 层精英，第 10 层章 Boss
  • 每章 10 层节点随机连接成分支路径图（3–5 层深度，横向 2–3 条支路）

6.2 节点类型

节点 内容
战斗 2–4 波怪，标准掉落
精英 1 只强化怪 + 护卫，必掉紫装以上
宝箱 开箱，装备品质随层数提升
商人 用金币买 1 件指定部位装备（品质随机，价格浮动）
事件 文本 + 二选一（例：用 30% 生命换一件紫装 / 失去 1 件装备换深渊结晶）
休整 恢复生命 + 免费洗练 1 条词缀
祭坛 献祭一件装备，换取本层一条诅咒词缀移除
首领 章 Boss，必掉套装部件

6.3 三选一诅咒词缀（每层进入时）

这是深渊的策略核心。玩家在层首从 3 条诅咒中选 1 条，选中后本层生效，效果写在屏幕左侧常驻。

普通档（1–10 层） — 单边收益 | 词缀 | 效果 | |---|---| | 贪婪 | 掉落品质 +1 档，但怪物属性 ×1.3 | | 孤军 | 召唤物数量上限 -1，自身属性 ×1.2 | | 灼热 | 每 5 秒受到一次真实伤害，掉落 +1 件蓝装 | | 铁壁 | 玩家格挡率归零，敌方掉落 +50% 金币 | | 沉默 | 主动技冷却 +30%，但击杀额外积累怒气 | | 群狼 | 怪物数量 +40%，但怪物攻速 -25% | | 黑暗 | 屏幕可视范围缩小，掉落率 +30% |

精英档（11–20 层） — 需要 Build 厚度 | 词缀 | 效果 | |---|---| | 词缀反转 | 本层所有增益词缀变为减益，减益变为增益 | | 生命献祭 | 最大生命 -40%，所有伤害 +40% | | 反伤之潮 | 受到伤害时反弹 50%，但玩家伤害 -20% | | 双面 | 玩家与敌人的护甲互换数值 | | 静默领域 | 玩家无法使用主动技 5 秒（每 20 秒触发） | | 掠夺 | 每 10 层不选祭坛则丢失 1 件装备 | | 血月 | 敌人血量随时间增长，只有速杀或爆发可解 |

章 BOSS 档（21+ 层） — 规则改写 | 词缀 | 效果 | |---|---| | 镜界 | 本章所有敌人属性 ×2，但掉落 Item Power ×1.6 | | 断链 | 套装效果全部失效，仅词缀生效 | | 单一 | 只掉落「武器」部位装备，其余部位本层不可用 | | 时间裂隙 | 每 30 秒未击杀敌人则全屏伤害，需持续输出 | | 深渊压榨 | 每层结束扣 8% 生命，深渊结晶产出 +60% |

6.4 层间操作（对应支柱二）

进入下一层前，玩家可对背包做三件事：

  • 锁定：把某件装备固定，下一层掉落时不覆盖它
  • 洗练：消耗残片重掷一条词缀
  • 跳过：主动放弃本层掉落，换取额外 1 个残片

这三个操作让玩家在每一层都有「停下来做决定」的时刻，而不是无脑清怪。

6.5 深渊产出

  • 装备（主产出）
  • 深渊结晶（附魔材料，深渊专属）
  • 残片（洗练材料）
  • 回响印记（通关章产出，用于兑换暗金图纸与套装图纸）
  • 每 10 层首通有 宝箱轮换：通关奖励池

7. 主线与副本的分工

主线 回响深渊
目的 扩装备池、解锁新词缀与基底 提升装备强度与定向刷取
关卡数 12 章 × 8–10 关 无限
时长 3–5 分钟/关 15–25 分钟/章
掉落 章节 Boss 保底紫 + 1 图纸 高频全品质 + 碎片 + 印记
策略 关卡内战斗解谜（打断、站位、时机） 局外 Build 与词缀取舍
新手引导 承担 不承担

关键设计：主线 = 「学会这套系统」，深渊 = 「精通这套系统」。新手在主线里被强制接触 7 个部位与技能栏竞争，深渊只是把选择权放大。

8. 铁匠铺经营线

铁匠铺是长线留存 + 数值回收系统，不承担核心战斗体验。

  • 委托单：NPC 发布（我要一件紫的护盾 / 给我 3 件任意腰带），完成给金币与声望，每日刷新
  • 声望等级：解锁图纸、委托类型、寄售位
  • 铁砧升级：用锻造石升级，解锁更高品质区间与更多洗练位
  • 学徒：可派学徒自动采集锻造石（放置玩法，离线产出），学徒属性可培养
  • 店铺外观：暗黑卡通的铁匠铺场景可装饰（挂件、灯光、旗帜），纯外观付费点

产能提示：铁匠铺 UI 全部是静态面板 + 图标 + 数字，不需要美术新场景（除 1 张主界面背景），是整个项目里性价比最高的一块内容。

9.3 通胀控制

  • 金币产出随装备品质提高而提高，但高等级鉴定费/寄售价呈超线性增长
  • 锻造石只来自分解 → 高品质装备越稀有，锻造石越缺 → 天然抑制囤积
  • 残片只来自深渊 → 离线玩家无法刷，强化在线时长

12. 音频规范

  • 战斗核心：重击音（低频）+ 元素特效音（高频）+ 受击闷响，三层混音

13.2 核心模块职责

模块 职责 关键约束
Equipment 装备实例、品质解析、词缀 roll、评分 纯函数，无节点依赖，可单测
Loot 掉落表查询、权重抽取、保底 纯函数 + 随机种子注入（便于回放与调试）
Build 7 部位属性聚合、技能栏装配、套装激活 纯函数，输入角色 + 背包，输出战斗快照
Curse 诅咒词缀的加载、叠加、结算修正 通过修正器链 (Modifier Chain) 作用于战斗数值
Combat 实体、状态机、技能结算、伤害管线 逻辑与表现分离，伤害管线支持 Modifier 插桩
Save 存档读写、版本迁移 见 13.4
DeepAbyss 节点图生成、层推进、状态机 纯逻辑 + 表现分离

13.3 修正器链（Modifier Chain）架构

诅咒词缀、套装效果、Buff/Debuff 全部走同一条修正链，避免系统爆炸：

基础属性 → [装备词缀] → [套装效果] → [诅咒修正] → [增益/减益] → [临时Buff] → 最终属性

新增一个机制 = 往链上插一个 Modifier，不需要改动战斗结算代码。这是支撑「40+ 诅咒 + 24 套装效果 + N 个状态」能共存的关键。

13.6 性能与包体

  • 对象池：怪物、特效、伤害数字全部池化，战斗峰值 60 单位不掉帧
  • 虚拟列表：背包 200+ 件装备用 ScrollView + 手动复用节点
  • 分包：装备图标 / 特效独立 bundle，按需下载
  • 纹理压缩：iOS 用 ETC2，Android 按渠道分级
  • 同图集：按部位 + 品质打图集，降低 DrawCall

13.7 联网版本（可选，第二阶段）

  • 客户端只与排行榜 / 寄售 / 好友通信，战斗与掉落全部本地计算
  • 掉落随机种子 + 战斗日志上报，服务端只做结果校验与反作弊，不做战斗演算
  • 寄售走服务端托管物品，装备进交易行前先做属性校验与唯一 ID 注册

16. 风险与待验证假设
