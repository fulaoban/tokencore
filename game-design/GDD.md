## 1. 设计支柱 (Design Pillars)

所有玩法决策最终都要能回溯到这三条，任何与之冲突的提案一律否决。

### 支柱一：装备即玩法，而非装备即数值
装备的**部位**决定你获得什么能力，而不是只决定你的攻击力大 3%。换一把武器不是把数字从 100 变成 103，而是把「三段挥砍」换成「贯穿突刺」，整套 Build 的手感会变。
> 落地约束：任何一次装备掉落，必须至少改变一项**行为**（技能形态、触发条件、结算方式）。纯数值提升的掉落只允许出现在 T0/T1 品质。

### 支柱二：每一次掉落都是一次赌
掉落是纯随机的，但玩家**永远有决策**：要不要为了「词缀更好但部位不对」的装备放弃当前 Build，要不要花残片洗掉一条不合 Build 的词缀。
> 落地约束：深渊内必须有「锁定 / 洗练 / 跳过掉落」三种玩家操作，任何掉落都不能自动进背包。

### 支柱三：暗黑卡通 = 高对比剪影，而非血腥写实
美术走剪影 + 描边 + 高饱和点缀，不做写实脏污。装备品质靠**发光边框 + 图标符号**区分，不靠精细贴图。
> 落地约束：单件装备图标成本预算 ≤ 15 分钟，7 部位 × 6 品质 = 42 个基础图标靠换色 + 换前缀角标复用。

## 2. 核心玩法支柱的实现结构

```
                    ┌──────────────────────────────┐
                    │        装备系统 (7 部位)       │
                    │  头盔 鞋 护盾 上衣 武器 腰带 裤子 │
                    └───────────────┬──────────────┘
                                    │ 每个部位 1主动 + 1被动
                                    ▼
   ┌────────────┐      ┌────────────────────┐      ┌────────────┐
   │  主线 12 章 │ ───► │   战斗 / Build 成型 │ ◄─── │ 铁匠铺经营  │
   │  剧情+词缀池│      │                    │      │ 锻造/附魔/洗练│
   └────────────┘      └─────────┬──────────┘      └────────────┘
                                  │
                        ┌─────────▼──────────┐
                        │  回响深渊 (Roguelite) │
                        │  节点地图 + 3选1诅咒 │
                        └────────────────────┘
```

三条内容线共用同一套装备与 Build 系统，任何一条线的产出都能在另一条线复用：
- **主线** → 提供新基底、新词缀池、套装图纸，决定「你的装备池有多大」
- **深渊** → 提供高频掉落与残片，决定「你的装备有多强」
- **铁匠铺** → 提供定向制造与词缀改造，决定「你的装备有多合身」

## 3. 世界观与叙事

### 3.1 设定
大陆历末，**深渊**裂开了一道口子。裂口不会喷出怪物，它**回放**——把死者生前的战斗一遍遍演给你看。每一场战斗都是某个人死前那一战的复刻。

「深渊回响」是冒险者对这道裂口的俗称。越往深处走，回响越清晰，到第七层你甚至能看见对手当年的走位和犹豫。

### 3.2 玩家身份
**拾遗者**：专门进入深渊、带回回响之物的赏金猎人。不问正义，只问价码。玩家的装备不是「打造」出来的，是从回响里**拾**回来的。

### 3.3 叙事载体（低成本、可扩展）
- **章节过场**：立绘 + 竖版对话框，每章 2–3 段
- **深渊日志**：进入深渊时随机抽 1–2 条前人日志（纯文本，几十条复用），提供世界感而不占产能
- **装备图鉴**：每件暗金附带一段短描述，收集即叙事
> 产能提示：叙事**不驱动**产能规划。12 章 × 3 段 = 36 段过场 + 60 条日志 + 12 件暗金描述 = 一名文案 + 一名兼职插画可覆盖。

### 3.4 12 章主线结构

| 章 | 区域 | 新增机制 | 解锁基底 | 新词缀池 | 套装 |
|---|---|---|---|---|---|
| 1 | 裂口边缘 | 基础战斗、掉落 | 破旧系全套 | 力量/体质 | — |
| 2 | 焦土荒原 | 元素伤害、精英怪 | 猎手系 | 火焰/流血 | 猎手三件（鞋+腰带+上衣） |

**章节 Boss 掉落**：本章套装的 1 个随机部位（保底紫）+ 1 张图纸（可定向打造套装剩余部位）。

## 4. 装备系统（核心）

### 4.1 七个部位

| 部位 | 英文 | 主属性倾向 | 携带主动技（示例） | 携带被动（示例） |
|---|---|---|---|---|
| 头盔 | Helmet | 生命 / 护甲 / 技能等级 | 恐惧冲击：AoE 眩晕 | 受击时附近敌人移速 -20% |
| 鞋 | Boots | 移速 / 闪避 | 疾影步：瞬发位移 + 突进 | 闪避成功后下次攻击 +50% 暴击 |
| 护盾 | Shield | 格挡率 / 格挡强度 | 壁垒：格挡窗口 + 反伤 | 受击积累怒气，满 100 释放 |
| 上衣 | Chest | 护甲 / 生命 / 减伤 | 血怒：消耗生命换攻击力 | 生命低于 30% 时自动获得护盾 |
| 武器 | Weapon | 攻击 / 暴击 / 技能等级 | 终结技：三段挥砍（主输出） | 暴击积累斩杀值，满值处决 |
| 腰带 | Belt | 吸血 / 治疗 / 药剂 | 药剂：即时治疗 + 解毒 | 击杀回复怒气 |
| 裤子 | Pants | 护甲 / 韧性 / 异常抗性 | 束缚：定身 + 沉默 | 异常状态持续时间 +25% |

**设计说明**：技能栏共 6 格，武器的主动技永久占据第 1 格，其余 5 格由其他 6 个部位竞争填充。玩家天然会产生「我该放弃哪个部位的技能」的选择——这就是 A 方案（装备即技能）的核心张力。

### 4.2 品质分级与命名规范

命名格式：**`[前缀] + [词缀名] + [部位名]`**，例：`深渊的猎颅头盔`、`不朽的裂魂战裤`。

| 品质 | 颜色 | 词缀数 | 前缀池 | 定位 |
|---|---|---|---|---|
| T0 破损 | 灰 | 0 | 破旧的 / 粗劣的 / 碎裂的 | 纯分解料 |
| T1 普通 | 白 | 1 | 普通的 / 木质的 / 铁制的 / 粗工的 | 过渡 |
| T2 精良 | 绿 | 2 | 厚实的 / 猎手的 / 锋利的 / 精工的 | 前期主力 |
| T3 稀有 | 蓝 | 3 | 秘银的 / 龙鳞的 / 亡者的 / 猎魂的 | 中期主力 |
| T4 史诗 | 紫 | 4 | 深渊的 / 血誓的 / 幽冥的 / 灾厄的 | 核心 Build |
| T5 传说 | 橙 | 5 + 1 传说特性 | 不朽的 / 炎魔的 / 永恒的 / 灭魂的 | 追求目标 |
| T6 神话 | 红 | 6 + 2 传说特性 | 原初的 / 虚空的 / 灭世的 / 终焉的 | 终极 |
| T7 暗金 | 橙红特殊框 | 改写规则 | 无前缀，专属名 | 收集 / 流派核心 |

**前缀规则**：
1. 前缀由品质决定，玩家的**基础词缀名永远带前缀**，一眼可判品质
2. 前缀决定该装备的**词缀倾向**（例：「炎魔的」必带火伤，「亡者的」必带吸血/召唤）
3. 前缀是**美术与音效的第一识别位**（图标左上角角标 + 名称首字高亮）

### 4.3 词缀系统

**通用属性池（无部位限制）**：攻击力、攻击速度、暴击率、暴击伤害、生命值、护甲、闪避、移速、伤害减免、格挡率、格挡强度、生命偷取、治疗加成、冷却缩减、技能等级、资源回复。

**元素属性池**：火焰 / 冰霜 / 雷 / 暗影 / 物理 伤害与抗性。

**状态池（异常）**：燃烧 / 流血 / 中毒 / 冰冻 / 眩晕 / 沉默 / 束缚 / 减速。

**部位→词缀权重**（决定掉落时的词缀偏向）：

| 部位 | 高权重 | 低权重 |
|---|---|---|
| 头盔 | 生命值、护甲、技能等级、冷却缩减、异常抗性 | 攻击速度、暴击率 |
| 鞋 | 移速、闪避、攻击速度 | 生命值、治疗加成 |
| 护盾 | 格挡率、格挡强度、护甲、生命值 | 移速、攻击速度 |
| 上衣 | 护甲、生命值、伤害减免 | 暴击率、移速 |
| 武器 | 攻击力、暴击率、暴击伤害、技能等级 | 生命值、护甲 |
| 腰带 | 生命偷取、治疗加成、药剂回复、资源回复 | 护甲、闪避 |
| 裤子 | 护甲、韧性、异常抗性、伤害减免 | 暴击伤害、资源回复 |

**关键约束（防组合爆炸）**：
- **部位不重复**：同一部位不会出现两条同权重词缀（如武器不会同时给两条攻击速度）
- **词缀可跨部位**：暴击率可出现在武器/鞋/头盔，形成多来源 Build 可能性
- **全局词缀上限**：同一词缀在 7 个部位上最多出现 3 次

### 4.4 套装系统
每个套装 3 件，激活「2 件效果」+「3 件效果」。套装效果**改变行为**而非只加数值。

| 套装 | 2 件 | 3 件 |
|---|---|---|
| 猎手 | 移速 +15% | 首次击杀敌人回复 8% 生命，攻速 +10% |
| 钟楼守望 | 受到控制时免疫 | 每 5 秒获得一次可抵挡一次伤害的护盾 |
| 骨王 | 召唤物 +1 且继承 30% 属性 | 召唤物死亡时爆炸造成范围伤害 |
| 炎魔匠 | 受到伤害积攒熔火值 | 熔火值满时，下次技能附带燃烧 |
| 血月使 | 生命低于 50% 时攻速 +25% | 生命低于 30% 时免疫控制 |
| 断罪官 | 击杀精英积累审判值 | 审判值满时对全场敌人处决（低血量必杀） |
| 虚空行者 | 技能伤害 +20% | 每 8 秒免疫一次负面状态 |
| 拾遗者 | 全部位主动技等级 +1 | 深渊内掉落品质概率提升（受福祸平衡） |

### 4.5 暗金（Unique）设计
7 件暗金，每件改写一条规则，是流派的核心载体。**不参与随机掉落**，全部通过图纸 + 深渊通关定向打造。

| 暗金 | 部位 | 规则改写 |
|---|---|---|
| 拾荒者的贪婪 | 腰带 | 背包内每件未装备的紫色以上装备，额外提供 3% 攻击力 |
| 无尽回响 | 武器 | 终结技第 3 段不消耗怒气，且必定暴击 |
| 碎骨者的宽容 | 裤子 | 致死伤害改为保留 1 点生命，每场战斗仅一次，冷却 30 分钟 |
| 守夜人的长明 | 头盔 | 恐惧冲击改为持续照明光环，范围内敌人无法沉默你 |
| 铁壁的裂痕 | 护盾 | 格挡不再消耗耐久，改为消耗生命，反伤翻倍 |
| 疾影的残响 | 鞋 | 疾影步可连用 3 次，每次留一道残影，残影 2 秒后爆炸 |
| 血契的代价 | 上衣 | 血怒改为永久生效，但每 10 秒扣 3% 最大生命 |

### 4.6 掉落生成算法

```
生成一件装备：
1. 决定品质     P(quality) = base[quality] × 幸运修正 × 深渊层数修正 × 套装标记
2. 决定部位     按怪物掉落表权重随机（精英/Boss 有部位权重偏移）
3. 决定基底     该部位该品质下的基底名池随机（如「猎颅」「裂魂」「守望」）
4. 决定前缀     从该品质前缀池随机 → 决定词缀倾向
5. 决定词缀     按部位权重池采样 N 条（互斥规则约束）→ 套用前缀倾向
6. 决定数值     每条词缀在 [min, max] 区间 roll，稀有度影响区间宽度
7. 判定传说特性  T5+ 概率触发 1 条，T6 概率触发 2 条（池按品质+部位限定）
8. 生成 Item ID  写入唯一实例 ID 与 roll 后的最终数值
```

**掉落表归属**：怪物身上挂 `dropTableId` → 表内定义 `equipChance`、`qualityWeights[]`、`slotWeights[]`、`minQuality`。章节越深，Boss 的 `minQuality` 越高。

### 4.7 装备评分 (Item Power)
用于 UI 快速对比与深渊难度匹配，不参与实际战斗计算。
`ItemPower = 品质基线(品质) × (1 + Σ词缀权重 × 0.08) × (1 + 传说特性数 × 0.15)`
品质基线：T0=1, T1=3, T2=8, T3=18, T4=35, T5=65, T6=110, T7=160

### 4.8 铁匠铺系统

| 功能 | 消耗 | 产出 | 说明 |
|---|---|---|---|
| 分解 | 装备 | 锻造石 + 部位碎片 | T0/T1 全自动，T2+ 需二次确认（防误分解） |
| 锻造 | 锻造石 + 图纸 | 指定部位 + 指定品质的新装备 | 品质由图纸决定，词缀随机；这是**定向获取套装**的路径 |
| 附魔 | 深渊结晶 | 给装备附加 1 条「特性」（非词缀） | 特性永久附加，可洗 |
| 洗练 | 残片 | 重掷某一条词缀的数值区间 | 只能洗数值，不改词缀类型与品质 |
| 鉴定 | 金币 | 开出未鉴定装备的真实属性 | 鉴定费随词缀数递增；鉴定前只显示颜色 |
| 分解进阶 | 锻造石 + 部位碎片 | 把 3 件同品质同部位合成 1 件高一品质 | 品质上限受图纸约束 |
| 订单 | — | 金币 + 声望 | NPC 每日订单：要某部位某品质以上 / 要某套装部件 |
| 寄售 | 金币 | 声望 | 把不需要的装备挂出去，等其他玩家买（可选，联网版） |

**未鉴定装备**是铁匠铺的核心张力来源：深渊里掉下一件未鉴定的橙装，你无法判断它是否值得洗练——先花金币鉴定还是先跑路？这是免费产生「二选一决策」的低成本设计。

## 5. 战斗系统

### 5.1 视角与操作
- **2D 等距视角**（45° 斜俯视），参考《暗黑破坏神》《火炬之光》手游化形态
- **虚拟摇杆移动 + 点击技能施放**，普攻自动索敌
- 单局怪物数量 8–25 只，全员同屏，靠位移与技能规避而非硬拼

### 5.2 技能系统
- 技能栏 **6 格**：第 1 格固定为武器主动技，其余 5 格由其他部位竞争
- 冷却采用**充能式**（充能数 = 基础充能 + 冷却缩减），避免"技能转好了却用不掉"的挫败
- 怒气/资源条：**普攻与击杀积累**，消耗释放，武器主动技是主要消费口
- 每个部位主动技有 **3 个等级**（来自装备技能等级词缀或铁匠铺强化），等级提升改变数值 + 解锁 1 个变体（如恐惧冲击 Lv3 变为吸附型）

### 5.3 敌人与战斗威胁类型
| 类型 | 行为 | 应对 |
|---|---|---|
| 近战冲锋 | 直冲玩家，接触伤害 | 位移 / 护盾格挡 |
| 远程弹幕 | 定点发射可躲避弹体 | 走位，不贪输出 |
| 施法者 | 蓄力 1.5s 后 AoE | 打断（用主动技） |
| 召唤者 | 持续生成小怪 | 优先清召唤者 |
| 护盾者 | 必须破盾才能伤害 | 集中爆发 |
| 回声者 | 复制玩家 3 秒前的操作 | 时机管理 |

**「回声者」是本作特色敌人**：它复刻玩家刚才的技能与走位，逼迫玩家改变行为而不是重复输出。设计意图是把「回响」世界观落到战斗机制上。

### 5.4 死亡与惩罚
- 普通关卡：原地复活，掉落物保留
- 深渊：死亡则本层掉落全部损失（**已拾取装备保留**，未拾取的留在尸体可二次拾取），损失一半深渊结晶
- 不做体力/耐久惩罚，只做**时间成本**惩罚

## 6. 回响深渊（Roguelite 副本）

### 6.1 结构
- 深渊分 **若干章（Depth Cycle）**，每章 10 层：第 1–8 层普通节点，第 9 层精英，第 10 层章 Boss
- 每章 10 层节点随机连接成**分支路径图**（3–5 层深度，横向 2–3 条支路）

### 6.2 节点类型
| 节点 | 内容 |
|---|---|
| 战斗 | 2–4 波怪，标准掉落 |
| 精英 | 1 只强化怪 + 护卫，必掉紫装以上 |
| 宝箱 | 开箱，装备品质随层数提升 |
| 商人 | 用金币买 1 件指定部位装备（品质随机，价格浮动） |
| 事件 | 文本 + 二选一（例：用 30% 生命换一件紫装 / 失去 1 件装备换深渊结晶） |
| 休整 | 恢复生命 + 免费洗练 1 条词缀 |
| 祭坛 | 献祭一件装备，换取本层一条诅咒词缀移除 |
| 首领 | 章 Boss，必掉套装部件 |

### 6.3 三选一诅咒词缀（每层进入时）
这是深渊的策略核心。玩家在**层首**从 3 条诅咒中选 1 条，选中后本层生效，效果写在屏幕左侧常驻。

**普通档（1–10 层）** — 单边收益
| 词缀 | 效果 |
|---|---|
| 贪婪 | 掉落品质 +1 档，但怪物属性 ×1.3 |
| 孤军 | 召唤物数量上限 -1，自身属性 ×1.2 |
| 灼热 | 每 5 秒受到一次真实伤害，掉落 +1 件蓝装 |
| 铁壁 | 玩家格挡率归零，敌方掉落 +50% 金币 |
| 沉默 | 主动技冷却 +30%，但击杀额外积累怒气 |
| 群狼 | 怪物数量 +40%，但怪物攻速 -25% |
| 黑暗 | 屏幕可视范围缩小，掉落率 +30% |

**精英档（11–20 层）** — 需要 Build 厚度
| 词缀 | 效果 |
|---|---|
| 词缀反转 | 本层所有增益词缀变为减益，减益变为增益 |
| 生命献祭 | 最大生命 -40%，所有伤害 +40% |
| 反伤之潮 | 受到伤害时反弹 50%，但玩家伤害 -20% |
| 双面 | 玩家与敌人的护甲互换数值 |
| 静默领域 | 玩家无法使用主动技 5 秒（每 20 秒触发） |
| 掠夺 | 每 10 层不选祭坛则丢失 1 件装备 |
| 血月 | 敌人血量随时间增长，只有速杀或爆发可解 |

**章 BOSS 档（21+ 层）** — 规则改写
| 词缀 | 效果 |
|---|---|
| 镜界 | 本章所有敌人属性 ×2，但掉落 Item Power ×1.6 |
| 断链 | 套装效果全部失效，仅词缀生效 |
| 单一 | 只掉落「武器」部位装备，其余部位本层不可用 |
| 时间裂隙 | 每 30 秒未击杀敌人则全屏伤害，需持续输出 |
| 深渊压榨 | 每层结束扣 8% 生命，深渊结晶产出 +60% |

### 6.4 层间操作（对应支柱二）
进入下一层前，玩家可对背包做三件事：
- **锁定**：把某件装备固定，下一层掉落时不覆盖它
- **洗练**：消耗残片重掷一条词缀
- **跳过**：主动放弃本层掉落，换取额外 1 个残片

这三个操作让玩家在每一层都有「停下来做决定」的时刻，而不是无脑清怪。

### 6.5 深渊产出
- 装备（主产出）
- 深渊结晶（附魔材料，深渊专属）
- 残片（洗练材料）
- 回响印记（通关章产出，用于兑换暗金图纸与套装图纸）
- 每 10 层首通有 **宝箱轮换**：通关奖励池

## 7. 主线与副本的分工

| | 主线 | 回响深渊 |
|---|---|---|
| 目的 | 扩装备池、解锁新词缀与基底 | 提升装备强度与定向刷取 |
| 关卡数 | 12 章 × 8–10 关 | 无限 |
| 时长 | 3–5 分钟/关 | 15–25 分钟/章 |
| 掉落 | 章节 Boss 保底紫 + 1 图纸 | 高频全品质 + 碎片 + 印记 |
| 策略 | 关卡内战斗解谜（打断、站位、时机） | 局外 Build 与词缀取舍 |
| 新手引导 | 承担 | 不承担 |

**关键设计**：主线 = 「学会这套系统」，深渊 = 「精通这套系统」。新手在主线里被强制接触 7 个部位与技能栏竞争，深渊只是把选择权放大。

## 8. 铁匠铺经营线

铁匠铺是**长线留存 + 数值回收**系统，不承担核心战斗体验。

- **委托单**：NPC 发布（我要一件紫的护盾 / 给我 3 件任意腰带），完成给金币与声望，每日刷新
- **声望等级**：解锁图纸、委托类型、寄售位
- **铁砧升级**：用锻造石升级，解锁更高品质区间与更多洗练位
- **学徒**：可派学徒自动采集锻造石（放置玩法，离线产出），学徒属性可培养
- **店铺外观**：暗黑卡通的铁匠铺场景可装饰（挂件、灯光、旗帜），纯外观付费点

**产能提示**：铁匠铺 UI 全部是静态面板 + 图标 + 数字，不需要美术新场景（除 1 张主界面背景），是整个项目里性价比最高的一块内容。

### 9.2 货币

|---|---|---|
| 金币 | 卖装备、NPC 委托、分解 | 鉴定、寄售、商铺、图纸 |

### 9.3 通胀控制

- 锻造石只来自分解 → 高品质装备越稀有，锻造石越缺 → 天然抑制囤积
- 残片只来自深渊 → 离线玩家无法刷，强化在线时长

## 13. 技术架构（Cocos Creator 3.8 LTS）

### 13.1 目录结构
```
assets/
  scenes/            # Boot / Login / Main / Battle
  scripts/
    core/            # Game, EventBus, DataManager, SaveManager, Timer
    data/            # 配置表读取与索引构建
    domain/          # 纯逻辑：Equipment, Affix, Loot, Build, Curse, Combat
    systems/         # 背包、装备、锻造、深渊、任务、商店
    ui/              # 面板与组件
    fx/              # 特效、伤害数字、屏幕震动
  resources/
    config/          # JSON 配置表（可热更）
    prefab/
    art/
  bundle/
    main/            # 主包
    dl_equip/        # 装备图标、词缀图标（分包）
    dl_fx/           # 特效（分包）
```

### 13.2 核心模块职责
| 模块 | 职责 | 关键约束 |
|---|---|---|
| `Equipment` | 装备实例、品质解析、词缀 roll、评分 | **纯函数，无节点依赖**，可单测 |
| `Loot` | 掉落表查询、权重抽取、保底 | 纯函数 + 随机种子注入（便于回放与调试） |
| `Build` | 7 部位属性聚合、技能栏装配、套装激活 | 纯函数，输入角色 + 背包，输出战斗快照 |
| `Curse` | 诅咒词缀的加载、叠加、结算修正 | 通过**修正器链 (Modifier Chain)** 作用于战斗数值 |
| `Combat` | 实体、状态机、技能结算、伤害管线 | 逻辑与表现分离，伤害管线支持 Modifier 插桩 |
| `Save` | 存档读写、版本迁移 | 见 13.4 |
| `DeepAbyss` | 节点图生成、层推进、状态机 | 纯逻辑 + 表现分离 |

### 13.3 修正器链（Modifier Chain）架构
诅咒词缀、套装效果、Buff/Debuff **全部走同一条修正链**，避免系统爆炸：

```
基础属性 → [装备词缀] → [套装效果] → [诅咒修正] → [增益/减益] → [临时Buff] → 最终属性
```

新增一个机制 = 往链上插一个 Modifier，**不需要改动战斗结算代码**。这是支撑「40+ 诅咒 + 24 套装效果 + N 个状态」能共存的关键。

### 13.4 配置表结构
四张核心表（JSON，热更）：

```json
{
  "id": 4,
  "name": "史诗",
  "color": "#8B5CF6",
```

**词缀表 `affix.json`**

**只存 roll 结果，不存词缀逻辑**，配置更新后老存档仍可正确还原。

```json
{
  "version": 3,
  "player": { "level": 35, "exp": 84210, "gold": 152300, "forgeStone": 890, "crystal": 44, "shard": 12, "echoMark": 3, "renown": 7 },
  "equipped": { "weapon": "inst_10231", "shield": "inst_10232", "helmet": null, "chest": null, "pants": null, "boots": null, "belt": null },
  "inventory": [
    {
      "uid": "inst_10231",
      "baseId": 1001,
      "quality": 4,
      "affixes": [ { "id": 2101, "value": 12 }, { "id": 2140, "value": 31 } ],
      "traits": [ { "id": 9001, "level": 2 } ],
      "locked": true
    }
  ],
  "unidentified": [ { "uid": "inst_10500", "baseId": 1007, "quality": 5 } ],
  "abyss": { "cycle": 4, "layer": 7, "nodePath": [1, 2, 0], "seed": 20241017 }
}
```

**存档版本迁移**：`SaveManager` 按 `version` 逐级迁移，配置表 id 重排时用 `baseId` 的稳定 id 而非数组下标。

### 13.6 性能与包体
- **对象池**：怪物、特效、伤害数字全部池化，战斗峰值 60 单位不掉帧
- **虚拟列表**：背包 200+ 件装备用 ScrollView + 手动复用节点
- **分包**：装备图标 / 特效独立 bundle，按需下载
- **纹理压缩**：iOS 用 ETC2，Android 按渠道分级
- **同图集**：按部位 + 品质打图集，降低 DrawCall

### 13.7 联网版本（可选，第二阶段）
- 客户端只与**排行榜 / 寄售 / 好友**通信，战斗与掉落**全部本地计算**
- 掉落随机种子 + 战斗日志上报，服务端只做**结果校验与反作弊**，不做战斗演算
- 寄售走服务端托管物品，装备进交易行前先做**属性校验与唯一 ID 注册**

| 机制 | 装备携带 1 主动 + 1 被动，6 格技能栏竞争填充，套装 2 件效果 |
| 装备来源 | 简化：只有掉落 + 背包 + 换装 + 分解 |
| 深渊 | 3 层线性节点 + 每层 3 选 1 诅咒（共 6 条） |
| **验证指标** | 玩家换装频次、7 部位选择分布是否均衡、技能栏是否出现"无解"配置 |

**这是整个项目的生死线**：如果 7 个部位的技能在实机上不好玩、或者出现某个部位"必选"导致其余 6 个形同虚设，A 方案的核心假设就崩了。此时 B/D/C 三个方案都只是它的降级版，需要立刻转向。

## 15. 商业化设计

| 类型 | 内容 | 原则 |
|---|---|---|
| 免费 | 全部主线、无限深渊、全部装备获取途径 | **不做 Pay to Win**，随机性即内容 |
| 付费 · 外观 | 角色皮肤、武器外观、宠物、界面主题、铁匠铺装饰 | 主收入来源 |
| 付费 · 便利 | 额外背包格、离线收益加速、自动分解队列、寄售位 | 不影响产出速率 |
| 付费 · 赛季 | 赛季通行证（30 级）、赛季限定外观、赛季词缀 | 赛季重置深渊进度，保留账号 |

**红线**：不卖装备、不卖深渊层数、不卖词缀数值。玩家付费可以变好看、变方便，不能变强。

## 16. 风险与待验证假设

| # | 风险 / 假设 | 影响 | 应对 |
|---|---|---|---|
| 1 | **7 部位技能在实机上是否好玩**（核心假设） | 致命 | V0.1 原型优先验证，1 个部位做废就重做设计而非打补丁 |
| 2 | 7 部位 × 6 品质 = 42 图标的产能 | 高 | 严格用换色 + 角标复用，禁止逐件手绘 |
| 3 | 组合爆炸（词缀 × 品质 × 部位 × 套装 × 诅咒） | 高 | 部位不重复规则 + 全局词缀上限 3 次 + 修正器链架构 |
| 4 | 数值通胀（掉落越刷越强 → 早期内容废弃） | 高 | 深渊层数收益递减曲线；主线章节提供「保底 + 定向」而非纯随机 |
| 5 | 2D 等距 + 20 只怪同屏的移动端性能 | 中 | 对象池 + 图集合并 + 分辨率自适应；V0.1 就跑真机压测 |
| 6 | 铁匠铺变成纯粹的重复劳动 | 中 | 订单 + 学徒放置 + 装饰，把经营做成有节奏的日常而非苦力 |
| 7 | 掉落全靠随机，前期玩家容易卡死 | 中 | 首个紫装保底（首领必掉）、未鉴定装备提供沉没成本与博弈点 |
| 8 | 单机 vs 联网的投入产出比 | 中 | 战斗与掉落全本地，联网只做排行榜与交易，先跑单机版 |
